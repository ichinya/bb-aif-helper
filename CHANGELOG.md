# История изменений

## 0.2.0 — 2026-11-02

- Над полем ввода показываются команды `$aif…` из последнего ответа агента, отдельно от карточки workflow.
- У каждой команды есть крестик: скрытие сохраняется для этого текста ответа после перезагрузки, без отправки сообщений.
- Запуск сохраняет черновик, проверяет установленный skill и актуальность ответа; доставка использует общую защиту от busy/pending/queue, дублей и неопределённого результата.
- Разбор ограничен именами команд, без аргументов/окружающего текста; новые тесты покрывают два предложения, скрытие, переключение чатов, гонку обновления ответа и отправку.

## 0.1.3 — 2026-11-02

- Исправлено ложное «не установлен» для skills Codex в проектах с несколькими runtime: BB `codex-app` распознаёт общую `.agents/skills`, зарегистрированную как `codex` или `universal`.
- Точное совпадение runtime остаётся приоритетным; каталоги других runtime не используются для совместимого поиска.
- Добавлены регрессионные проверки discovery, `aif-analyze`, отсутствующих файлов и fingerprint; всего 55 тестов.

## 0.1.2 — 2026-11-02

- Постоянная кнопка AI Factory в заголовке и отдельная вкладка справа.
- Панель читает статус своего чата без поиска карточки; открытие не отправляет workflow-команду.
- SDK harness проверяет открытие и thread scope; всего 51 тест.

## 0.1.1 — 2026-11-02

- Обновление AI Factory и запуск `aif`/`aif-analyze` независимо от плана.
- Обнаружение `aif-analyze` среди custom skills установленного `aifhub-extension`.
- Версии установки в fingerprint; updater-запрос сохраняет владельца установки и локальные изменения.

## 0.1.0 — 2026-11-02

- Карточки в чате и контекстной секции: версии, расширения, задачи и отчёты проверок.
- Маршруты upstream, AIFHub classic/OpenSpec и отдельный legacy ultra.
- CLI, agent tool и host RPC для read-only статуса.
- Защита от устаревших карточек, повторных кликов, неопределённой доставки и запуска во время работы.

Даты отражают подготовку локальных версий, а не публикацию в npm или создание GitHub Releases.
